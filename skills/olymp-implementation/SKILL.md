# Implementation

Follow the project's coding guidelines and established conventions. Prefer the smallest change that fulfills the outcome, reusing existing code where suitable. Produce working, readable, well-structured, maintainable code; apply separation of concerns, SOLID, Clean Code, and other practices where they help rather than adding unnecessary abstractions. Validate the changed behavior with suitable tests and project checks, and report results and limitations.
